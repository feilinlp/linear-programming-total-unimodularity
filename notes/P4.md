**The message of Slide 5 · 1/2 (When is TU useful?):** TU is a property of the constraint matrix, not an algorithm. It does two things:
1. **Explains known algorithms** (flows, bipartite matching): why integral optima exist, and duality theorems (max-flow min-cut, König) for free.
2. **Solves problems with no classic algorithm** (shift scheduling): model as an ILP, check TU, solve the LP once.
And TU is **fragile**: overnight shifts break it, so it must be checked, not assumed.

## 1. The three applications (for the report, §4)

Plan for each: write the LP → identify the constraint matrix → prove it is TU (using P1/P2's tools).

### 1.1 Max-flow (L4–L6)
- **LP:** variables f_e for each arc e. Maximise net flow out of s, subject to conservation Σ_in f − Σ_out f = 0 at every v ≠ s, t, and 0 ≤ f_e ≤ c_e.
- **Matrix:** conservation rows = directed node–arc incidence matrix N (each column has at most one +1 and one −1); capacity rows = identity. Stacking N, −N and I keeps TU.
- **Proof that N is TU** (induction on the size k of a square submatrix): if some column is all zero, det = 0; if some column has exactly one nonzero, expand along it and use induction; otherwise every column has one +1 and one −1, so the rows sum to 0 and det = 0.
- **Consequence:** integer capacities ⇒ every vertex integral ⇒ an integral max flow exists. This is L6's integrality theorem as a special case of Hoffman–Kruskal.
- **Baselines:** Edmonds–Karp O(m²n), Dinic O(n²m) (L6). Used in E4.

### 1.2 Bipartite matching and vertex cover
- **Matching LP:** max Σ_e x_e s.t. Σ_{e ∋ v} x_e ≤ 1 for every vertex v, x ≥ 0.
- **Dual:** min Σ_v y_v s.t. y_u + y_v ≥ 1 for every edge {u, v}, y ≥ 0. This is the VC LP (README notation).
- **Matrix:** vertex–edge incidence of a bipartite graph = transpose of P1's B. TU by P1's result (bipartite ⇔ TU), and TU is closed under transposition. Proof idea: negate the rows of one side; each column then has one +1 and one −1, so it is a directed incidence matrix (row negation does not change |det|).
- **König's theorem:** both LPs are TU, so both have integral optimal vertices. Strong duality (L7) makes the values equal. So max matching = min vertex cover in bipartite graphs. On C₄: matching {v₁v₂, v₃v₄}, cover {v₁, v₃}, both size 2.
- **Contrast:** on C₃ the matching LP has x_e = ½, value 1.5, but the max matching is 1. Not TU.
- **Baseline:** Hopcroft–Karp O(m√n) (networkx). Used in E4.

### 1.3 Shift scheduling
- **ILP:** hours t = 1…T with demand d_t; each shift j covers a block of consecutive hours and costs c_j. Minimise Σ c_j x_j s.t. Σ_{j covers t} x_j ≥ d_t for each hour t, x ≥ 0 integer.
- **Matrix:** rows = hours, columns = shifts; each column has consecutive 1s (an *interval matrix*).
- **Proof that interval matrices are TU** (via P2's Ghouila-Houri): take any subset of rows, order them by hour, and give them signs +, −, +, −, … For each column, its 1s among the chosen rows are consecutive in this order, so the signed sum is 0 or ±1. Hence TU.
- **Consequence:** the LP relaxation already returns an integral schedule. A generic ILP solver (branch-and-bound) stops at the root node: no branching.
- **Side fact (optional for report):** subtracting consecutive rows turns an interval matrix into a network matrix, so shift scheduling is secretly a min-cost flow problem (attributed to Veinott & Wagner 1962, unverified).
- **Where TU breaks:** overnight shifts wrap around (circular 1s). Example: 3 hours in a cycle, demand 1, shifts {1,2}, {2,3}, {3,1}. The constraints are exactly the VC LP on C₃: LP = (½, ½, ½) with value 1.5, integer optimum 2. Still solvable with a few LPs (Bartholdi, Orlin & Ratliff 1980, unverified), but no longer TU.
